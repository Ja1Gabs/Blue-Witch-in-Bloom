# 🌸 Blue Witch in Bloom (IN PRODUCTION)

### A 2D Platformer Game made with Godot

> *Blue Witch in Bloom* is a personal game development project focused on learning programming logic, game design, and the fundamentals of game creation using the Godot Engine.

---

## 🧙 About the Project

**Blue Witch in Bloom** is an original indie game project developed in the Godot Engine using **GDScript** (a Python-inspired language).
The project was started as a learning journey to deepen my understanding of programming logic, especially concepts related to Python, while also exploring the creative process of game development.

Rather than being just a prototype, this project is designed as a structured personal study in:

* Game logic and architecture
* Player mechanics
* Combat systems
* Level design
* Narrative-driven gameplay

---

## 🎮 Game Concept

The game follows the journey of a young witch in search of her purpose, exploring mystical environments, facing unique enemies, and growing through challenges across different stages.

Core design philosophy:

* Small handcrafted stages
* Creative bosses per map
* Collectibles that grant progression bonuses
* Atmospheric and stylized world

## 🚀 How to Run the Project

### Requirements:

* Godot Engine (recommended: Godot 4.x)

### Steps:

1. Clone the repository:

```bash
git clone https://github.com/your-username/Blue-Witch-in-Bloom.git
```

2. Open Godot Engine
3. Click on **Import Project**
4. Select the `project.godot` file
5. Run the project inside the engine
